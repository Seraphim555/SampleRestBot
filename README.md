# Сервисный бот для ресторана

Telegram-бот для гостя ресторана. Можно посмотреть справку, позвать официанта или забронировать столик.

Авторы: Лев и Виктория.

## Что умеет бот

Команда `/start` начинает диалог заново и показывает меню.

В меню три кнопки:

- **Info.** Бот присылает меню файлом, адрес с фотографиями (Екатеринбург, ул. Тургенева, д. 4) и блюдо месяца. Из этого раздела можно вернуться назад.
- **Вызов официанта.** Бот отвечает, что официант сейчас подойдёт.
- **Забронировать столик.** Бронь идёт по шагам: ближайшие три дня, число гостей от 1 до 6, время. Свободный столик нужного размера записывается в MySQL. Если он занят, бот берёт больший. Если свободных нет, так и пишет.

На фото, стикер и любой не-текст бот отвечает, что ждёт текст.

Пользователь сохраняется в MySQL. Имя в базе хранится в зашифрованном виде.

## Стек

Java 17, Spring Boot, Spring Data JPA, MySQL, библиотека TelegramBots, Maven. В репозитории есть Dockerfile.

## Запуск

Нужны JDK 17, Maven и MySQL 8.

Создайте базу:

```sql
CREATE DATABASE IF NOT EXISTS `tg-bot` CHARACTER SET utf8mb4;
```

Адрес базы, логин и пароль лежат в `src/main/resources/application.properties`. Таблицы создаются при старте (`spring.jpa.hibernate.ddl-auto=update`).

Токен бота берите у [@BotFather](https://t.me/BotFather) и передайте переменной `BOT_TOKEN1`. В `application.properties` он уже читается оттуда.

PowerShell:

```powershell
$env:BOT_TOKEN1 = "токен"
.\mvnw.cmd spring-boot:run
```

При каждом запуске таблица броней очищается и заполняется заново: сегодня и два следующих дня, слоты с 12:00 до 22:00 каждый час, столы на 2, 4 и 6 человек. Часть слотов помечается занятыми случайно. Бронь, которую гость сделал до перезапуска, пропадает.

## Docker

Образ собирается так:

```powershell
docker build -t sample-rest-bot .
```

Внутри контейнера приложение ищет MySQL на `localhost:3306`. Если база запущена на вашей машине, из контейнера этот адрес до неё не дойдёт. Для проверки проще запускать через Maven.
